## 范围与阅读方式

- 本目录覆盖 **39 个 HTML 页面文件、28 份配套 Markdown 文档，另有本矩阵自身**；含主入口、报告、知识页、旧版与组件预览，数量不等于独立产品数。
- 外部收编 InsightChat、Constraint Lens、MindSpeed 配置关系平面页的**资料索引**，保留原项目，不复制源码、数据或部署材料。
- 本目录链接相对此文件。外部链接假定仓库同处 `D:/Projects/`：[InsightChat](../../InsightChat/README.md)、[mindspeed-config-mcp](../../mindspeed-config-mcp/README.md)、本仓库 `compute-graph-viewer-wzh/`。跨仓库链接供本机查阅，发布本仓库静态站点后不会自动包含外部文件。
- `vendor/`、`node_modules/`、`AscendProfKit/`、各 `skills/` 内部资料不逐项展开；`Analysis Report/` 作为证据集单列。

## 运行与依赖

多数本仓库页面需**从仓库根目录启动 HTTP 服务**，保留根级 `vendor/pto-design-system/`、跨目录数据、脚本与 iframe 相对路径。例如：

```powershell
Set-Location D:\Projects\compute-graph-viewer-wzh
npx --yes http-server . -p 8765 -c-1
```

访问 `http://127.0.0.1:8765/Profiling_Insight_and_Tool/...`。已安装 Python 时也可用 `python -m http.server 8765`。根目录没有统一构建 / 测试入口，独立子项目按各自 `package.json` 运行。

不能再概括成“全部是单文件、均不可 file://”：Observer、Rank、分析工作台等依赖多文件；静态 MCP 包自包含，Learning 离线快照和 Constraint Lens 等有各自磁盘直开方式。部分分析页还依赖 CDN。
